                        接下来的 3 个步骤
================================================================================

步骤 1️⃣：Vercel 部署（5分钟）
---------------------------------
🔗 访问：https://vercel.com/new

操作：
1. 用 GitHub 登录
2. 导入 "policy-prediction-market" 仓库
3. 添加环境变量：
   NEXT_PUBLIC_SUPABASE_URL = https://placeholder.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY = placeholder
4. 点击 Deploy
5. 记录你的网站 URL：https://________.vercel.app


步骤 2️⃣：Supabase 数据库（5分钟）
---------------------------------
🔗 访问：https://supabase.com/dashboard/new/_

操作：
1. 用 GitHub 登录
2. 创建项目：
   - Name: policy-prediction-market
   - Password: 设置强密码（记住！）
   - Region: Tokyo 或 Singapore
3. 等待初始化完成
4. SQL Editor → New query
5. 复制粘贴 supabase-init.sql 的全部内容
6. 点击 Run
7. Settings → API，复制：
   - Project URL: https://________.supabase.co
   - anon public key: eyJhbGci...


步骤 3️⃣：连接配置（3分钟）
---------------------------------
A. 更新 Vercel 环境变量：
   - 回到 Vercel → Settings → Environment Variables
   - 更新为真实的 Supabase URL 和 Key
   - Deployments → Redeploy

B. 配置 Supabase 回调：
   - Supabase → Authentication → URL Configuration
   - Site URL: https://你的域名.vercel.app
   - Redirect URLs: https://你的域名.vercel.app/auth/callback
   - Save
